# Flood Prediction System v2

Surma & Kushiyara River Basin - Multiple Regression Model

## Live Demo
https://nagibmahmud.github.io/flood-prediction/

## Features
- Multiple linear regression using Rainfall, Avg Temp, Max Temp
- Predicts Surma and Kushiyara river water levels
- Flood risk analysis with threshold monitoring
- RMSE model validation
- Interactive charts

## Based on MATLAB Code
`flood_analysis_v2.m` - Translated to JavaScript for web deployment
